## 📖 About the Project

**EasySewa** is a mobile application UI/UX design project for an on-demand home services platform inspired by service marketplaces such as Urban Company. It is designed to help users explore home and personal care services, review service options and pricing, discover nearby providers, and access booking information through a structured mobile interface.

The project was designed in **Figma**, focusing on user-centered design, intuitive navigation, visual hierarchy, consistent interface components, and usability.

The design covers the user journey from mobile authentication and service discovery to service selection, cart review, address selection, and booking history.

## 🎨 Color Theme & Visual Language

The EasySewa design uses a clean, service-oriented visual style with green accents, light backgrounds, and clearly separated content cards.

- **Green Accent Theme:** Highlights important actions and supports brand consistency.
- **Light Backgrounds:** Keeps content readable and the interface uncluttered.
- **Neutral Surfaces:** Separates cards, forms, and content sections.
- **Typography Hierarchy:** Differentiates titles, service names, descriptions, and prices.
- **Gradients & Effects:** Provide visual emphasis where applied in the design.
- **Consistent Spacing:** Improves alignment and readability.
- **Icons & Illustrations:** Help users recognize service categories and actions.

---

## 🧩 UI Components & Design Elements

The interface uses recurring design patterns to maintain consistency across screens.

- **Service Cards:** Images, service names, descriptions, and navigation actions.
- **Pricing Elements:** Clear presentation of service names and prices.
- **Navigation Elements:** Back controls and bottom navigation.
- **Input Components:** Mobile number entry and verification-code fields.
- **Action Buttons:** Primary actions for progressing through the intended user flow.
- **Booking Cards:** Appointment details, provider information, and booking actions.
- **Location Elements:** Map-based provider markers and address-selection layouts.
- **Status Indicators:** Ratings, booking states, and supporting information.

Reusable components can make future design updates easier and improve consistency across multiple screens.

## 🔄 User Flow

The proposed user journey follows these stages:

1. **Authentication:** Enter a mobile number and proceed through the OTP verification interface.
2. **Service Discovery:** Browse home and personal care service categories.
3. **Service Selection:** Review service options and pricing.
4. **Cart Review:** Review selected services and payment-summary information.
5. **Address Selection:** Choose the location where the service is requested.
6. **Provider Discovery:** Explore the location-based provider interface.
7. **Booking Review:** View upcoming appointments and booking history.

This describes the intended interface journey represented by the designed screens.

## 📐 Responsive Design Considerations

The designs are mobile-oriented. The following principles can guide further refinement:

- Use Auto Layout to maintain consistent spacing within supported components.
- Apply frame constraints and resizing rules to manage element positioning.
- Adapt service cards and content layouts for different mobile screen sizes.
- Maintain readable typography and appropriately sized touch targets.
- Prevent text, images, and action buttons from overlapping.
- Test layouts across different frame dimensions.

Responsive behavior should be validated across screen sizes rather than assumed from a single mobile layout.
