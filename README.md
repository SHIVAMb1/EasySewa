## 📖 About the Project

**EasySewa** is a mobile application UI/UX design project for an on-demand home services platform inspired by service marketplaces such as Urban Company. It is designed to help users discover and request home and personal care services through a simple, intuitive mobile interface.

The design covers service categories, service options and pricing, location-based provider discovery, and booking history. The goal is to make the service discovery and booking journey clear, convenient, and easy to navigate.

The project was designed using **Figma**, with a focus on user-centered design, visual hierarchy, consistent interface components, and usability.

## 🔄 User Flow

1. **Login:** Enter a mobile number through the designed login interface.
2. **Browse:** Explore service categories.
3. **Select:** Review service options and prices.
4. **Discover:** View the location-based provider interface.
5. **Request:** Continue through the designed service-request interaction.
6. **Review:** View upcoming and previous bookings.

---

## 🧠 Design Approach

- **User-Centered Design:** Focused on common service discovery and booking tasks.
- **Visual Hierarchy:** Used typography, spacing, and color to highlight important information.
- **Consistent Components:** Maintained consistent buttons, cards, icons, and navigation elements.
- **Intuitive Navigation:** Organized screens around a clear user journey.
- **Usability:** Prioritized readability and clear interface actions.
