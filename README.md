## 📖 About the Project

**EasySewa** is a mobile application UI/UX design project for an on-demand home services platform inspired by service marketplaces such as Urban Company. The concept is designed to help users discover, explore, and request home and personal care services through a simple and intuitive mobile interface.

The application focuses on making service discovery and booking easier by organizing service categories, displaying service options and pricing, presenting nearby service providers, and providing access to booking history.

The interface designs were created in **Figma**, with an emphasis on user-centered design, visual hierarchy, consistent components, and intuitive navigation.

This project demonstrates practical skills in **mobile application UI/UX design, user flow design, interface structuring, and usability-focused visual design**.

## 🔄 User Flow

The proposed user journey is organized around the following steps:

1. **Login:** Enter a mobile number and proceed through the designed verification flow.
2. **Browse Services:** Explore available home and personal care service categories.
3. **Select a Service:** View service options, descriptions, and pricing.
4. **Discover Providers:** View the location-based provider discovery interface.
5. **Request a Service:** Use the designed service-request interaction.
6. **Review Bookings:** Access the booking history interface to view appointment information.

This flow represents the intended interface journey, not a claim that a functional backend or booking system has been implemented.

## 🧠 UI/UX Design Approach

### User-Centered Design

Focused on common user tasks, including finding a service, comparing options, understanding pricing, and reviewing appointments.

### Visual Hierarchy

Used typography, spacing, color, and visual grouping to make key information easier to scan.

### Consistent Interface Components

Maintained consistency in buttons, cards, icons, navigation elements, and service listings across the designed screens.

### Intuitive Navigation

Structured the screen layouts around a clear journey from service discovery to service selection and booking-related information.

### Usability-Focused Layouts

Prioritized readable text, recognizable icons, clear actions, and organized information to support a straightforward mobile experience.

## 🏗️ Design Architecture

The design is organized into three conceptual layers:

| Layer | Responsibility |
|---|---|
| **Presentation Layer** | Screen layouts, typography, colors, cards, icons, and interactive elements |
| **Navigation Layer** | User journeys connecting authentication, service categories, service details, location, and booking history |
| **Service Interaction Layer** | Proposed interface interactions for service requests, provider discovery, and booking management |

These are conceptual design layers rather than implemented software modules.

## ⚠️ Project Scope & Limitations

- The current project focuses on UI/UX design rather than a fully implemented application.
- Login, verification, booking, and tracking screens represent interface concepts.
- Live provider availability and location data are not confirmed as implemented.
- Backend integration, authentication, database storage, and payment processing are outside the documented design scope.
- The screenshots represent the designed user interface, not proof of a production deployment.
